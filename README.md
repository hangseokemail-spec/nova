# Nova

서아가 직접 기획한 주간 어린이 과학 신문 웹앱입니다. 매주 금요일 밤 10시에 새 호가 나옵니다.

## 파일 구성

- `index.html` 웹앱 전체(화면, 퀴즈, 스도쿠, 잠금, 질문 상자)
- `editions/index.json` 발행된 호 목록. `publishAt`이 지나야 화면에 보입니다.
- `editions/YYYY-MM-DD.json` 호마다 기사, 퀴즈, 스도쿠, 영상, 그림 데이터
- `config.js` 기록 서버(Apps Script 웹 앱) 주소. 비어 있으면 기록은 기기 안에만 남습니다.
- `apps_script/Code.gs` 구글 시트 "Nova 데이터베이스"에 붙이는 기록 서버 코드
- `.nojekyll` GitHub Pages가 파일을 그대로 내보내게 하는 표시

## 새 호 내기

1. `editions/새날짜.json`을 만들고 `editions/index.json`의 `issues`에 한 줄을 더합니다.
2. `publishAt`을 금요일 22:00(한국 시각, `+09:00`)으로 둡니다. 일찍 올려도 그 시각 전에는 보이지 않습니다.
3. 원고, 기록, 운영 메모는 구글 드라이브 `AI/Nova` 폴더에 둡니다.

## 지켜야 할 것

- 이 저장소는 공개입니다. 퀴즈 기록, 좋아요, 질문 같은 서아의 기록은 저장소에 넣지 않고 구글 시트에만 둡니다.
- 먼작귀 만화는 번역하거나 복사하지 않고 공식 게시물을 원본 그대로 띄웁니다.
