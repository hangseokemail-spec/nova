# 서아 페이퍼 제0호 기자용 공통 안내

## 편집장(Fable) 글쓰기 원칙
1. "~해요"체, 한 문장에 한 가지 내용. 뉴스 본문 400~500자, 깊이 코너 본문 900~1,200자(공백 포함, 낱말 풀이·출처 제외).
2. 첫 문장은 질문이나 장면으로 시작. 낯선 낱말은 나올 때 바로 풀어 줌.
3. 숫자·이름·날짜는 확인한 출처에 있는 것만. 없는 내용은 지어내지 않고, "가능성"과 "밝혀짐"을 구분.
4. 큰 숫자는 한 기사에 2~3개만, 아이가 아는 것에 견줌(예: 0.2초는 눈 깜빡임보다 짧음).
5. 겁주는 표현, 훈계, "너희도 열심히" 식 결말, 과장("세계 최초", "완벽") 금지. 퀴즈로 낼 문장은 본문에 분명히 한 번 나오게.

## 공통 규칙
- 모든 글과 메모는 한국어로만 쓴다(학명·고유명사 원문은 괄호로 함께 써도 됨).
- 독자: 초등 4학년 여자아이 서아. 과학 뉴스는 초등 고학년~중학생이 이해할 수 있는 수준으로 쉽고 재밌게. 깊이 코너는 깊이 읽을 수 있게.
- 출처 문장을 그대로 옮기지 말고 자기 말로 다시 쓴다. 따옴표 인용은 하지 않는다.
- 사용자 컴퓨터를 다루는 도구(이름이 mcp__remote-devices 로 시작하는 도구)는 절대 쓰지 않는다.
- 먼작귀(치이카와) 같은 남의 캐릭터를 그리게 하는 그림 지시는 쓰지 않는다. 글에서 이름을 말하는 것은 괜찮다.

## 결과 파일 형식 (JSON, UTF-8)
{
  "id": "영문 소문자 아이디",
  "corner": "코너 이름",
  "title": "제목(25자 안팎)",
  "sub": "부제 한 줄",
  "body": [ {"t":"p","x":"문단"}, {"t":"h","x":"소제목"}, {"t":"box","title":"상자 제목","x":"상자 내용"}, {"t":"list","items":["...","..."]}, {"t":"think","x":"생각해 보기 질문"} ],
  "words": [ {"w":"낱말","m":"쉬운 뜻"} ],          // 3~5개
  "sources": [ {"t":"출처 이름","u":"URL"} ],
  "art_brief": "이 기사에 들어갈 그림 한 장 설명(무엇을, 어떤 느낌으로). 글자 없는 그림.",
  "facts": [ {"claim":"기사에 쓴 사실 하나","source":"그 사실을 확인한 URL"} ],   // 숫자·이름·날짜가 들어간 문장은 모두
  "quiz": {
    "쉬움":   [문제, 문제],
    "보통":   [문제, 문제],
    "어려움": [문제, 문제]
  }
}
문제 형식(세 가지 중 하나):
- OX:   {"type":"ox","q":"문장","answer":"O" 또는 "X","explain":"해설 한두 줄"}
- 객관식: {"type":"mc","q":"질문","options":["보기1","보기2","보기3","보기4"],"answer":정답 번호(0부터),"explain":"해설"}
- 주관식: {"type":"short","q":"질문","answer":"한 낱말이나 숫자","accept":["허용 답들"],"explain":"해설"}
퀴즈 정답의 근거는 반드시 본문에 있어야 한다. 주관식 답은 한 낱말이나 숫자만.
파일을 다 쓰면 python3 -m json.tool 파일 > /dev/null 로 형식을 검사한다.
