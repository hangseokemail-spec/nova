- 발행: 매주 금요일 밤 10시(한국 시각). 제1호 2026-11-17(창간호), 제2호 2026-11-20.
- 편집인: 서아 아빠(교사). 모든 대화와 보고는 반드시 한국어로만 해요. 영어로 답하지 않아요.

### 1. 기록 위치 (구글 드라이브 'AI/서아 페이퍼' 폴더. 폴더 id는 정기 작업 지시문에 있어요)
- 01_기획·운영: 운영 기록, 결정 사항, 이 지침 사본
- 02_발행본: 호마다 '제N호 (날짜)' 폴더를 만들고, 원고 모음(문서), 한 파일 HTML, 사이트 묶음을 넣어요
- 03_수학 자료: 편집인이 넣는 4학년 수학 문제 파일. 있으면 수학 퀴즈 수준을 여기에 맞춰요
- 04_디자인: GPT 만화 의뢰서와 받은 그림(예: Nova1_만화.png, Nova2_만화.png)
- 기사 데이터베이스(표): 'Nova 기사 데이터베이스'. 드라이브 연결로는 표 내용을 고칠 수 없으니, 호마다 같은 열 구성의 CSV를 새 표로 올려요
- 드라이브 문서로 올릴 때 4바이트 이모지는 빼요(깨져요). 파일 참조 업로드는 작업 폴더 안의 파일만 돼요(/tmp는 안 됨).

### 2. 구성 (탭)
표지(한 화면에 들어오는 잡지 표지) · 차례(차례, Nova 읽는 법, 편집장 글) · 과학(뉴스 2편) · 수학(깊이 2편, 도형이면 직접 해 보는 시뮬레이터) · 경제(2편) · 예술(2편) · 문학(책 3권) · 심리검사(재미로 하는 검사 + '좋아하는 것' 1편) · 만화 · 스도쿠(9×9 두 판, 각각 답이 하나) · 퀴즈(뉴스·수학, 쉬움·보통·어려움, 잠금 없음) · 영상(4편)
- 2026-11-19 편집인 결정(제2호부터): 기사 탭은 정확히 2편씩, 먼작귀 탭은 없앰, 스도쿠 9×9 두 판. 글 수준과 풀이는 제1호와 같게.
- 동기 부여(기기마다 따로 기억): 스도쿠를 다 맞히면 축하 효과와 그 판 위 왕관, 기사를 끝까지 읽으면 '다 읽었어요' 도장(차례에도 표시).
- 무엇이든 물어보세요: 정식 사이트는 config.js의 askUrl(편집인 AWS Lightsail 서버의 nova_ask, 편집실/site/ask_server/README.md)로 바로 답해요. 아티팩트 판은 Claude가 바로 답해요.
- 퀴즈를 풀어야 무엇을 볼 수 있는 잠금은 두지 않아요.
- 모든 뉴스에 출처 링크. 영어 출처에는 '국문 요약'을 붙여요(서아는 영어를 못 읽어요).

### 3. 글 기준 (가장 중요)
- 독자는 초등학교 4학년. "최대한 쉽고 자세하게, 비유를 많이, 모를 것 같은 낱말은 풀어서. 이걸 보는 사람이 4학년임을 잊지 말 것." 동시에 유치하면 안 돼요(어린이과학동아 수준, 감탄·아기 말투 금지).
- 한 문장 60자 이하, 한 문단 2~4문장. 어려운 낱말은 처음 나올 때 괄호 풀이 + terms 목록(화면에서 점선 밑줄, 누르면 뜻).
- 풀이 없이 쓰면 안 되는 기초어: 입자, 에너지, 센서, 세포, 단백질, 원자, 분자, 화학, 탄소, 포유류, 평균, 부피, 세기(100년), 학술지, 논문, 관측, 기여, 관여, 한계, 오류 등.
- 큰 숫자는 몸으로 느낄 비유로 바꾸고, 바꾼 숫자는 반드시 python으로 계산해 확인.
- 기사 끝에 '생각해 보기'(정답 없는 질문 2개). 집에서 할 수 있는 안전한 활동이면 '직접 해 보기'.
- quote 블록은 기사 핵심 요약 한 문장(화면에 '핵심'으로 표시). 누가 한 말처럼 쓰지 않아요.
- 사실은 출처에 있는 것만. 출처에 없는 이름·숫자·국적·'세계 최초' 금지. 연구의 의도를 단정하지 않아요.
- 원고 형식: 편집실/drafts/README_새형식.md, 3판 기준: 편집실/drafts/README_v3.md, 검수원 지침: 편집실/drafts/README_검수원.md

### 4. 꼭지별 기준
- 책: 신간이 아니라 평점·리뷰 수·판매 지표로 골라요. 알라딘(목록 쪽 별점·리뷰, 상품 쪽 100자평+리뷰, 세일즈포인트)과 예스24(검색 결과의 평점·리뷰 수·판매지수)를 함께 봐요. 서점은 조회수를 공개하지 않으니 판매 지표로 대신한다고 밝혀요. 만화·문제집 제외, 문학·과학·사회/경제 등 분야를 나눠 3권. 이미 소개한 책은 다시 소개하지 않아요. 표지는 알라딘 이미지(출처 표시).
- 영상: 서로 주제가 겹치지 않게 4편(예: 그리기, 만들기, 실험·자연, 이번 호 기사와 연결). 한국어이거나 말이 없는 영상, 15세 미만 시청 가능, 믿을 만한 채널 우선. 유튜브 공개 검색 결과 쪽(curl)에서 조회수·올린 때·채널을 보고 골라요. 비공개 API나 우회는 쓰지 않아요. 좋아요·댓글을 못 읽으면 못 읽었다고 밝혀요. 이미 소개한 영상은 다시 넣지 않아요. 먼작귀 영상은 넣지 않아요.
- 그림: 기사 그림은 Fable 편집장의 그림 작업지시서대로 GPT 그림(장면, 만화 말고 5장 이하, '일러스트' 표시)과 SVG 도판(숫자·축척이 필요한 그림)으로 나눠요(README_오퍼스4인.md 3절).
- 만화: 편집부가 직접 그리지 않아요. 4~8칸의 재미있는 이야기를 쓰고, GPT 이미지 모델용 의뢰서를 써서 04_디자인에 올려요(예시: 편집실/drafts/GPT_만화_의뢰서_v3.md). 그림체는 '작고 귀여운 일상 만화(가늘고 살짝 떨리는 선, 동글동글한 2~3등신, 단순한 얼굴, 볼 터치, 파스텔 수채)'처럼 말로만 설명하고, 특정 작품·캐릭터 이름은 넣지 않아요. 주인공은 서아가 만든 마스코트(주황빛 작은 동물, 뾰족 귀, 큰 눈, 작은 송곳니). 그림 속 글자는 넣지 않고, 칸 배치는 2칸×3줄+가로 긴 마지막 칸처럼 자르기 쉽게. 받은 그림은 편집실/comic_slice.py로 잘라 대사를 얹어요. 그림이 없으면 콘티만 싣고 '그림 준비 중'으로 둬요.
- 예술: '그림 속 과학'이 아니라 작품 감상. 무엇을 봐야 하는지, 무엇이 아름다운지, 생각을 넓히는 질문. 그림을 크게 보여 주므로 저작권이 끝난 작품만(한국 작가는 1962년 이전 사망, 외국 작가는 1955년 이전 사망). 위키미디어 공용 퍼블릭 도메인 파일(설명이 붙은 User-Agent, 1920px 축소본). '가까이 보기' 3~5곳은 그림을 직접 보고 좌표를 정해요.
- 경제: 『열두 살 경제 놀이터』(이효석·이하윤)처럼 아빠가 서아에게 하나하나 가르치는 대화체("아빠: …", "서아: …"). 생활 소재에서 뉴스 개념으로 한 계단씩. 퍼센트는 '100원당 몇 원'으로.
- 수학: 도형이나 움직임이 나오면 직접 조작하는 시뮬레이터를 만들어 넣어요(제1호의 연필 돌리기 시뮬레이터: template_v3.html의 simHtml/bindSim 참고). 4학년 범위의 수와 계산만.
- 무엇이든 물어보세요: 4학년 눈높이로 답해요(조립 코드의 ASK 문구).

## Nova 제작 방식: Opus 기자 4명 + Fable 편집장 (2026-11-19부터)

편집인 결정(2026-11-19): Haiku·Sonnet은 쓰지 않아요. 기사 탭(과학·수학·경제·예술·심리)은 정확히 2편씩, 책 3권·영상 4편, 스도쿠 9×9 두 판, 먼작귀 탭 없음. 글 수준과 풀이는 제1호와 같게. Opus 기자 4명이 파트를 나눠 1차 원고를 쓰고, Fable 편집장이 깊이 있는 피드백과 그림 작업지시서를 써요. 그림은 GPT에 의뢰해 받고, 4명이 그림까지 함께 보며 협의해 최종 원고를 편찬해요.

모든 지시와 보고는 한국어로만. 사용자 컴퓨터 도구(mcp__remote-devices로 시작) 금지. 웹은 WebFetch 대신 Bash `curl -sL -A "Mozilla/5.0" URL`. API 키는 어디에도 쓰지 않아요.

- 호 폴더: `편집실/issues/<금요일 날짜>/`

  - `drafts/` 1차 원고 → `final/` 최종 원고

  - `협의록.md` 공동 협의 기록

4. **GPT 그림 의뢰(편집인)**: 작업지시서를 드라이브 04_디자인에 올리면 편집인이 ChatGPT에 붙여 넣고, 받은 그림을 금요일 13:30까지 04_디자인에 지정 파일 이름으로 올려요. (Claude는 GPT를 직접 부를 수 없어요.)

6. **편찬(금요일)**: 진행 담당이 `final/`로 조립(build 스크립트 복사·수정), 표지·차례·편집장 글, 그림 넣기, 시험(390×844, 1280×900, 가로 넘침, 퀴즈 채점, 시뮬레이터, 콘솔 오류) → 저장소·아티팩트·드라이브(CLAUDE.md 6장).

### 3. GPT 그림 기준
- 기사 그림은 Nova 디자인과 맞게: 레트로 잡지 일러스트(잉크 선화, 종이 질감, 빨강 #C8372D·남색 #1F3A5F 위주, 망점). 만화만 파스텔 수채 일상 만화체.
- 그림 안에 글자·숫자를 넣지 않아요(라벨은 화면에서 얹음).
- 실제 사건 사진처럼 보이게 그리지 않아요. 화면에는 '일러스트'로 표시해요. 실제 망원경 사진·실제 동물 사진을 흉내 내지 않아요.
- 특정 작품·캐릭터 이름 금지. 실존 인물 얼굴 금지.
- 과학적으로 맞게: 의뢰문에 '맞아야 하는 것'(몸 구조, 크기 비율, 자세)을 출처에 근거해 적어요.
- 파일 이름: `Nova<N>_g<번호>_<짧은 이름>.png`, 만화는 `Nova<N>_만화.png`. 가로세로 비율을 의뢰문에 적어요(기사 3:2, 표지 4:5).
- 그림이 안 오면 SVG 도판(art_v2.py 형식)이나 콘티로 대신하고 '그림 준비 중'을 남기지 않아요(만화만 예외).
- 조립: 받은 그림은 `assets/img/n<N>_g<번호>.jpg`(1600px 이하)로 줄여 넣고, 기사 figs에 `{"img":"n<N>_g<번호>","cap":...,"credit":"그림: Nova 편집부 의뢰, AI 생성 일러스트"}`처럼 넣어요. 템플릿이 figs.img를 아직 그리지 않으면 편찬 때 template·build에 작게 더해요(지난 호 화면이 깨지지 않게).

### 4. 화면 (template_v4.html, build_v4.py)
- 스도쿠를 다 맞히면 색종이·팡파레 효과와 그 판 위 왕관, 기사를 끝까지 읽으면 '다 읽었어요' 도장(차례·탭에도 표시). 모두 기기마다 따로 기억(localStorage).
- 무엇이든 물어보세요: 아티팩트 판은 Claude가 바로 답하고, 정식 사이트는 config.js의 askUrl(편집실/site/ask_server, 편집인 AWS 서버)로 답해요. askUrl이 비어 있으면 '아직 연결되지 않았어요' 안내.

# 원고 기준 (README_v3)

## Nova 제1호 3판 원고 기준 (기자용)

공통: 한국어로만. 사용자 컴퓨터 도구(mcp__remote-devices 로 시작) 사용 금지. 웹 페이지는 WebFetch 대신 Bash로 `curl -sL -A "Mozilla/5.0" URL` 로 읽는다. 원문 문장을 옮기지 말고 자기 말로 쓴다.

### 독자: 초등학교 4학년(10살) 서아
- 서아는 그림 그리기, 만들기, 먼작귀(귀여운 캐릭터)를 좋아한다. 영어 글은 못 읽는다.
- 4학년이 아는 것: 큰 수(만, 억, 조), 곱셈과 나눗셈, 분수 기초, 각도(도), 시각과 시간, 평면도형. 모르는 것: 소수 계산 대부분, 비율·퍼센트, 제곱, 차원, 대부분의 과학·경제 용어.
- 편집인 요청(그대로 지킬 것): "최대한 쉽고 자세하게. 비유를 많이 들고, 모를 것 같은 낱말은 설명해 줄 것. 이걸 보는 사람이 초등학교 4학년임을 잊으면 안 된다."
- 동시에 유치하면 안 된다. 어린이과학동아처럼 내용은 진짜이고 말은 쉬운 글. 금지: "친구들~", "~했답니다", 느낌표 남발, 의성어 남발, 귀여운 척.

### 쓰는 법
1. 문장은 짧게. 한 문장 40자 안팎, 길어도 60자. 한 문단은 2~4문장.
2. 어려운 낱말은 처음 나올 때 바로 뒤에 괄호로 쉬운 풀이를 붙인다. 예: "중성미자(아주아주 작은 알갱이의 한 종류)". 그리고 같은 낱말을 terms 목록에도 넣는다. terms는 5~10개, 풀이(m)는 4학년 말로 한두 문장, 가능하면 비유 하나.
3. 비유를 문단마다 하나쯤. 큰 숫자는 몸으로 느낄 수 있게 바꾼다(예: "259억 km는 서울에서 부산까지 약 6만 번 왕복하는 거리"). 바꾼 숫자는 반드시 직접 계산해서 맞는지 확인한다(python으로).
4. 글의 흐름: (1) 궁금증을 부르는 장면이나 질문 → (2) 무슨 일이 있었나 → (3) 그게 왜 대단한가 → (4) 과학자들은 어떻게 알아냈나 → (5) 아직 모르는 것.
5. 기사 끝에 box 하나: title "생각해 보기", 정답이 없는 질문 2개(items). 사고력을 넓히는 질문으로. 집에서 해 볼 수 있는 활동이 있으면 "직접 해 보기" box를 하나 더 넣어도 된다(안전한 것만).
6. quote 블록은 기사의 핵심을 한 문장으로 요약한 것(화면에 '핵심'이라는 표시로 나온다). 누가 한 말처럼 쓰지 않는다. 1개만.
7. 글 길이: 본문 1,600~2,600자. 길어져도 쉬우면 괜찮다. 소제목(h)은 3~5개, 질문형도 좋다.
8. 사실: 2판(v2) 원고의 facts와 sources 안에서만 쓴다. 새 사실을 넣으면 출처(URL)와 facts를 추가한다. 숫자를 바꾸지 않는다. 검수 지적(아래 파일)은 모두 반영한다.
9. 퀴즈: 쉬운 말로 다시 쓴다. 쉬움 2, 보통 2, 어려움 2. 정답은 하나만. 본문에 근거가 있어야 한다.
10. figs: 그림은 이미 그려져 있다. cap(그림 설명)만 쉬운 말로 다시 쓰고, 그림 내용과 맞게 쓴다(아래 '그림 목록' 참고). brief는 2판 것을 그대로 둔다.

### 형식
2판과 같다(/home/claude/seoa/build/drafts/README_새형식.md). 다 쓰면 /home/claude/seoa/build/v3/<id>.json 으로 저장하고 `python3 -m json.tool` 로 검사한다.

### 그림 목록(이미 있는 그림, 바꾸지 않음)
- voyager: 1광일을 빛의 이동 시간으로 견준 그림(지구에서 달 약 1초, 태양에서 지구 약 8분 19초, 보이저 1호 24시간을 가로 막대로 비교)
- leonid: 복사점 한 점에서 유성이 사방으로 뻗어 나오는 모습
- icecube: 남극 얼음 단면. 얼음 속으로 내려간 빛 센서 줄들, 중성미자가 부딪혀 생긴 파란 빛
- crow: 까마귀 실험 시간선. 점 등장 → 70밀리초 신경세포 갈라짐 → 평균 235밀리초 응답
- dino: 공룡 팔다리뼈 단면 → 혈관 통로 → 광물이 된 적혈구 → 헴 분자
- kelp: 노 젓는 배 위에서 원격 조종 잠수정으로 켈프 숲 바닥의 성게를 세는 모습
- kakeya: 왼쪽 원(바늘 한가운데를 잡고 돌린 자리), 오른쪽 델토이드(세 뾰족 별 모양, 앞뒤로 밀며 돌린 자리). 이 기사에는 직접 돌려 보는 시뮬레이터가 함께 실린다.
- cute: 어른 얼굴과 아기 도식이 뚜렷한 얼굴 비교, 눈 높이 빨간 점선

# 문체·길이 기준 (README_잡지기준)

## 서아 페이퍼 잡지 기준 (제1호 개편, 2026-11-17)

아빠 지시: 너무 유치원 느낌이다. 초등 과학동아처럼 약간은 전문적인 느낌과 글로. 디자인은 심플하고 간결한 레트로 신문 느낌의 잡지.
참고 기준: 어린이과학동아. 최근 표지 주제가 "54년 만에 다시 달 간다! 아르테미스", "보이지 않지만 존재한다 암흑물질"처럼 본격 과학 주제이고, 한 권이 164쪽 분량이다. 쉬운 말로 풀되 주제와 정보의 깊이는 진짜 과학 잡지 수준이다.

### 문체
- 해요체는 유지하되 기자의 보도 문체로 쓴다. "~했어요", "~로 나타났어요", "연구팀은 ~라고 설명했어요", "~라는 뜻이에요".
- 문장은 보통 길이(20~45자). 한 문장에 한 정보. 감탄사, 의성어, "우와", "짜잔", 이모지, "~지요?" 남발 금지. 과장("세계 최초", "완벽") 금지. 훈계 금지.
- 전문 용어는 정확히 쓴다. 처음 나올 때 괄호로 짧게 풀고, "용어 정리"에 넣는다. 한 기사 새 용어 5개 이내.
- 구조(뉴스): 리드(무엇이 새로 밝혀졌나, 왜 중요한가, 2~3문장) → 배경 → 누가·어디서·어떻게 연구했나 → 결과(숫자와 비교) → 의미 → 한계와 남은 질문.
- 구조(특집·깊이): 리드 → 소제목 3~4개 → 정보 상자 1~2개("한눈에 보기", "더 알아보기", "직접 해 보기") → 마무리(남은 질문).
- 제목: 신문식. 핵심 사실과 강한 동사. 작은따옴표 강조 허용. 예: 까마귀, 0.2초 만에 '결정'… 사람보다 두 배 빨랐다
- 데크(부제): 기사 전체를 한 문장으로.
- 연구자 말은 직접 인용하지 말고 간접 인용으로 옮긴다.
- 확인한 사실만. 가능성과 밝혀진 것을 구분한다. 숫자는 단위와 익숙한 비교를 함께.
- 길이(본문, 공백 포함): 과학 뉴스 700~900자, 특집·깊이 1,400~1,800자, 경제·예술 1,200~1,600자.

### 출처
- 기사마다 sources에 모든 출처를 넣는다: {"t":"기사 제목(원문 그대로)","pub":"매체·기관","date":"YYYY-MM-DD","u":"URL","lang":"ko" 또는 "en"}.
- 영어 출처는 진행 담당이 따로 국문 요약을 붙인다(아이가 영어를 못 읽음). 기자는 lang만 정확히.

### 그림 설명
- figs: [{"cap":"그림 설명(캡션) 한 문장","brief":"도판 설명: 무엇을 어떤 도식으로. 선화+한두 색, 글자 라벨 허용"}] 1~2개.

### 디자인 기준(진행 담당용)
- 종이색 #F4EFE4, 잉크 #1C1A17, 빨강 #C8372D, 남색 #1F3A5F, 회색 #6B655C.
- 서체: 제목·본문 Noto Serif KR, 라벨·탭 Noto Sans KR. 이중 괘선, 단 나누기, 드롭캡, 캡션, 정보 상자 테두리.
- 도판: 잉크 선화 + 빨강/남색 + 망점. 파스텔·귀여운 장식 금지.
